## 2. Template Proyek Komolang

Mulai proyek baru dengan template resmi yang siap pakai:
- `komo baru --template=web my_web_app` (RESTful API & Fullstack)
- `komo baru --template=game my_game_2d` (Engine KomoGame 60 FPS)
- `komo baru --template=cli my_tool` (Command-Line Utility)
- `komo baru --template=lib my_package` (Pustaka Komopaket yang dapat diterbitkan)
