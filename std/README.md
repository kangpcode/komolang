# Pustaka Standar Komolang (`std`)

<!-- Copyright (c) kangpcode (Dhafa Nazula Permadi). Licensed under MIT or Apache-2.0. -->

Folder ini memuat modul-modul pustaka standar (*standard library*) resmi untuk bahasa Komolang. Pustaka standar dirancang tanpa dependensi eksternal, berkinerja tinggi, dan menggunakan konvensi penamaan Bahasa Indonesia.

## Rencana Modul Standar (Tahap 6):
- `std/cetak`: Operasi I/O terminal dan pemformatan teks.
- `std/teks`: Manipulasi string UTF-8, pemotongan, pencarian, dan penggabungan.
- `std/matematika`: Fungsi matematika dasar dan lanjutan (`sin`, `cos`, `akar`, dll).
- `std/larik` & `std/peta`: Struktur data koleksi tambahan.
- `std/waktu`: Operasi waktu, durasi, dan kalender.
- `std/berkas`: Operasi sistem berkas (membaca, menulis, direktori).
- `std/jaringan`: Soket TCP, UDP, TLS, dan klien HTTP.
- `std/uji`: Framework pengujian unit dan benchmarking.
