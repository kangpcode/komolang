# KomoWeb (Webserver & Framework Web)

<!-- Copyright (c) kangpcode (Dhafa Nazula Permadi). Licensed under MIT or Apache-2.0. -->

**KomoWeb** adalah modul web server dan framework HTTP native untuk Komolang, direncanakan pada **Tahap 9** dari peta jalan arsitektur.

## Target Kapabilitas:
- Server HTTP/1.1 dan HTTP/2 native berkinerja tinggi.
- Router berbasis Radix Tree tanpa alokasi berlebih.
- Dukungan WebSocket terintegrasi.
- Middleware, templating, session, dan CORS.
- Perintah CLI `komo layani` untuk pengembangan dengan hot-reload.
- Integrasi konkurensi task ringan (`jalankan` + `saluran`).
