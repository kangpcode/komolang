# KomoGame (Library & Engine Game)

<!-- Copyright (c) kangpcode (Dhafa Nazula Permadi). Licensed under MIT or Apache-2.0. -->

**KomoGame** adalah library dan runtime mesin game berkinerja tinggi untuk Komolang, direncanakan pada **Tahap 11** dari peta jalan arsitektur.

## Target Kapabilitas:
- Game loop presisi tinggi dengan target 60+ FPS stabil.
- Arsitektur ECS (*Entity Component System*) berbasis cache-friendly data layout.
- Abstraksi rendering 2D/3D modern (Vulkan, Metal, DirectX 12, WebGPU).
- Penanganan input periferal (keyboard, mouse, gamepad).
- Audio mixer multikanal dengan latensi rendah.
- Integrasi fisika 2D/3D dasar.
